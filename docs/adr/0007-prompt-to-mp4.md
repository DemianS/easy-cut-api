# ADR 0007: Первый монтаж по промпту

- Статус: принято
- Дата: 2026-10-20

## Решение

Сохранять MontageRun с пользовательским запросом, планом поиска, подборкой,
выбором и диагностикой. Каждый запуск создаёт Project и неизменяемую
TimelineVersion. Родительский Job продвигается диспетчером через короткие
дочерние стадии plan/search/select/render. Повторная доставка одной стадии
защищается PostgreSQL advisory lock; heartbeat обновляется во время IO.

Два структурированных вызова Ollama: секции с поисковым текстом и бюджетом,
затем candidate_id и длительность клипов. Backend ищет описания целых планов
через pgvector строго внутри выбранного корня и asset_ids, проверяет реальные
источники и убирает дубли. Кандидаты содержат превью, описание, similarity,
границы и snapshot исходника. LLM не задаёт пути и shell. Для одиночного клипа
отрезок берётся из середины разрешённого плана; при нескольких клипах одного
источника backend последовательно выделяет свободные интервалы. Точность
действия не гарантируется. Backend нормализует предложенные моделью бюджеты
секций по целевой длительности на кадровой сетке.
Не покрытые секции завершаются insufficient_material без автоматического
расширения области. Подборка и выбор доступны для просмотра через API.

Timeline-v1: миллисекунды, одна дорожка, скорость 1, последовательные клипы,
прямые склейки. Профиль mp4-1080p25-v1: H.264/yuv420p, 1920×1080, 25 FPS,
fit/pad, SAR=1, AAC stereo/48 kHz, исходный звук или тишина.
Длительности кратны 40 ms; target 1–120 s округляется до ближайшего кадра.
Проверять output через ffprobe с допуском 120 ms; затем атомарно публиковать.
Временные нормализованные части нужны только для рендера, удаляются после
попытки; рабочая область ограничена 4 GiB и таймаутом. После падения тот же
job очищает только собственный временный каталог при повторном запуске.

API /api/v1/montages: create/status/timeline/download, preview по ID кадра.
Idempotency-Key связан с полным телом запроса; несовпадение даёт 409.
Существующие API остаются совместимыми. POST означает согласие на
автоматическую сборку после валидации. ADR 0009 добавляет `auto_render=false`,
ручной выбор и отдельный запуск рендера версии.

## Ограничения

Качество зависит от описаний и модели; MP4 не означает смысловую полноту.
Изображения и отдельное аудио не участвуют в первом монтаже. Коллекции,
музыка, переходы, temporal-сегменты и редактор отложены. Повторяемость
рендера определяется сохранённым timeline и неизменностью исходников,
а не повторным недетерминированным вызовом LLM.
